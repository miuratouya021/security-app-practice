# security-app-practice

## 概要

COACHTECH 教材 Tutorial 10-6「Webセキュリティ ハンズオン」で作成した成果物です。

Laravelを使用して、お問い合わせフォームを作成しました。
名前・メールアドレス・メッセージを入力して送信すると、送信完了画面に入力内容が表示されます。

## 使用技術

- PHP 8.x
- Laravel 10.x
- Laravel Sail
- CSRF 保護（`@csrf`）、XSS 対策（Blade の自動エスケープ）
  （**他に使ったものがあれば追記してください**）

## 学んだこと

- @csrf を使用することで、不正なフォーム送信を防ぐ仕組みを学びました。
- Bladeの {{ }} を使用することで、入力されたスクリプトが実行されないようにするXSS対策を学びました。

## 動作確認

Laravel Sailを起動します。

ブラウザで http://localhost/contact にアクセスします。

名前・メールアドレス・メッセージを入力して送信します。

送信完了画面に入力内容が表示されることを確認します。
